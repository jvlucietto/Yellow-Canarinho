# Yellow Canarinho

Um jogo de plataforma 2D desenvolvido como projeto pessoal, com arte em pixel art e trilha sonora inteiramente autorais.

## Sobre o projeto

Este foi meu primeiro projeto de jogo de plataforma 2D. Desenvolvi o jogo com o objetivo de aprender e explorar diferentes aspectos do desenvolvimento de jogos, desde a programação das mecânicas até a criação dos elementos visuais e sonoros.
